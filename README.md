# 🤖 DebugMind AI

> **AI-Powered Developer Assistant for Code Review, Debugging, Explanation & Optimization**

DebugMind AI is a full-stack AI-powered developer assistant that helps developers analyze, review, explain, optimize, and debug source code using the **Google Gemini API**. It delivers real-time AI responses with **Server-Sent Events (SSE)**, making code assistance fast, interactive, and context-aware.

🌐 **Live Demo:** https://debugmind-ai-pi.vercel.app/

---

## ✨ Features

- 🤖 AI-powered code review
- 🐛 Intelligent bug detection
- 💡 Code explanation with detailed reasoning
- ⚡ Code optimization suggestions
- 📝 Advanced prompt engineering workflows
- 📡 Real-time AI response streaming (SSE)
- 🔒 Secure authentication
- 📱 Responsive modern UI
- 🚀 Fast and interactive developer experience
- 🧠 Foundation for AI Agent & MCP integration

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/boopathiraja26/debugmind-ai.git

cd debugmind-ai
```

### Install Dependencies

#### Client

```bash
cd client
npm install
```

#### Server

```bash
cd server
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_gemini_api_key
```

---

## ▶️ Run Locally

### Backend

```bash
npm run dev
```

### Frontend

```bash
npm run dev
```
